Agent skill + CLI for Claude Code, Codex and Cursor · MIT

Research‑first UI design for your AI coding agent.

front-design makes your agent read the experts and measure professional sites before it designs, add one modern effect with a reason, and audit the result until it passes.

Install
$ pip install -e ".[capture]"
$ python -m playwright install chromium
$ front-design install-skill

Run inside a local checkout. Then ask your agent to design something, or see the seven steps it follows.

01 / The loop

Seven steps, each one checked

Your agent still makes the design calls. The CLI does the parts that should be objective: sources, measurements, scales, contrast and the audit.

  1. 01 Brief

    Pin down audience and the one action

    Three brand adjectives, constraints and competitors go into brief.toml.

    front-design init "…" --type landing
  2. 02 Principles

    Read the experts, quote them exactly

    71 curated sources ranked by evidence. Every quote is checked against the live page.

    front-design note add --quote "…"
  3. 03 References

    Measure real professional sites

    Desktop and mobile screenshots plus fonts, type scale, palette, spacing and effect libraries.

    front-design capture <urls>
  4. 04 Direction

    Decide with reasons, lock tokens

    Two or three real options, each citing principles and references. Fluid type scale, contrast matrix.

    front-design scale --space
  5. 05 Effects

    Choose one signature effect

    28 effects with pinned versions, licenses and a reduced-motion path for each.

    front-design effects --vibe warm
  6. 06 Build

    Build with real copy and tokens only

    No lorem ipsum, no invented customers or numbers, every state designed.

    build/index.html
  7. 07 Audit

    Audit until it passes, then hand over

    Contrast on real pixels, targets, focus, motion, mobile. Then one HTML dossier.

    front-design audit build/index.html

04 / Effects

Modern effects, with manners

A catalog of 28 entries with snippets checked against each library's docs. The agent picks one signature effect that expresses the brand, not one of everything.

Paper Shaders
Mesh Gradient, Grain Gradient, Dithering, God Rays, Liquid Metal, Fluted Glass and the rest of the set
WebGL scenes
Unicorn Studio, ShaderGradient, Spline, three.js and React Three Fiber, OGL, COBE globe
Component collections
React Bits, Magic UI, Aceternity UI, Motion Primitives
Motion
Motion, GSAP with ScrollTrigger and SplitText, Lenis, Rive, dotLottie, NumberFlow, AutoAnimate, Vaul and Sonner
Web platform
View Transitions, scroll-driven animations, OKLCH, color-mix, @property, @starting-style
  1. One signature, two helpers at most

    Several WebGL canvases fighting for one viewport is the fastest way to look like a template.

  2. Reduced motion is a real path

    Shaders drop to speed 0, smooth scroll stays off, parallax goes static. The audit compares both modes.

  3. Contrast is measured on pixels

    Text is hidden, the page is photographed, and the background under every line is sampled, so text over a shader is checked too.

  4. Versions are pinned

    Paper Shaders ships breaking changes under 0.0.x. Every entry records the version that was checked.

05 / Audit

It does not stop at “looks fine”

The audit runs the page in Chromium on desktop and mobile and in reduced-motion mode. The agent fixes findings and re-runs it until the score passes.

0/100

Test page with planted problems: 12 error types found, from pixel contrast to a 1200px element on a phone.

100/100

The fixed test page, including a live shader that stops under reduced motion.

100/100

This page, audited with the same command before you saw it.

  • Text contrast on real pixels, desktop and mobile
  • Touch targets under 24 by 24 px (WCAG 2.5.8)
  • Keyboard focus visible and not hidden by sticky headers
  • Motion with prefers-reduced-motion: reduce
  • Horizontal overflow at 390 px
  • Links, buttons and fields without names or labels
  • Line length, line height, centered paragraphs
  • Font families, type-scale drift, spacing grid
  • Console errors, layout shift, page weight
  • Heading order, image alt, lorem ipsum, zoom blocking
