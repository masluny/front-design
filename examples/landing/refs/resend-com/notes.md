# Resend (developer-tool taste reference)

URL: https://resend.com

## Observations

- Layout and grid: left-aligned hero on 1280px container, sticky nav, 13 tall sections (summary.md).
- Hero pattern: two-line serif display headline (96px) + 2-line subhead + filled "Get started" and text "Documentation"; 3D object on the right.
- Section sequence: hero > integrate code samples > developer experience > feature blocks.
- Type pairing and voice: serif display (domaine/Favorit per tokens) against Inter text and commitMono code: editorial headline makes a dev tool feel crafted.
- Color strategy: pure black page, light gray text #a1a4a5 at 8.37:1, accents only in code highlights.
- Signature detail / effect: three.js object with soft light; huge type scale jump (H1 96px vs body 14px, ratio 1.25).
- What to borrow: serif display + mono for a developer audience; generous left-aligned hero; restraint with accent.
- What to avoid: 14px body text (too small for long reading, P11/Butterick); dark theme (our adjective "warm" and the paper notebook idea point to light).
