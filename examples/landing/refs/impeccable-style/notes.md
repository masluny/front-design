# Impeccable (direct competitor)

URL: https://impeccable.style/

## Observations

- Layout and grid: 2-column hero (interactive before/after demo left, headline right), ~1090px content, sticky top nav with GitHub star count.
- Hero pattern: condensed light display (Alumni Sans Hero) headline "The missing design vocabulary for agents." + one filled black CTA "Install Impeccable" + text link "How it works" + row of agent logos.
- Section sequence: hero > testimonial marquee > "Detects and removes AI slop" gallery of anti-patterns > interactive "Start with what you want to change" command demo.
- Type pairing and voice: Albert Sans body + JetBrains Mono for commands + condensed display; confident, playful copy ("AI slop").
- Color strategy: near-white #f8f8f8, black ink, yellow #ffba00 annotation labels, teal dot accent (summary.md).
- Signature detail / effect: annotated before/after slider; yellow callout labels naming anti-patterns. The demo IS the explanation.
- What to borrow: show the tool working on something real (before/after, real command); a single filled install CTA; annotation labels as a visual language.
- What to avoid: their exact look (condensed display + yellow labels); testimonial marquee (we have no real users to quote, brief forbids invented ones); centered paragraph on mobile.
